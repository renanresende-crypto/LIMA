A intuição do projeto era criar uma pagina para o SENAI que mostrava os cursos, constava uma apresentação que seria o Sobre na pagina e um formulario de contato.
A pagina possui cinco seções sendo:
Inicio
Video
Cursos
Sobre
Contato
As cores escolhidas foi Cinza,Preto,Branco, Vermelho, Cinza claro
Escolhi o vermelho por ele ser uma identidade ja do SENAI e ajuda a destacar os botões e dar uma vida para o site
Utilizei HTML e CSS
